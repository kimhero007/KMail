# KMail 邮件助手

魔兽世界：**无限**（forever 分支，1.60.x 独立客户端）专用邮件插件。

## 功能

- **一键收信**：收取全部邮件的金币与附件
- **通讯录**：收藏 / 好友 / 公会 / 最近 / 自己（同账号其他角色），点一下填进收件人

## 设计原则

- 只读 + 只领取：不删信、不退信
- 跳过货到付款（COD）与 GM 来信，需玩家手动确认
- 动作间留 0.2 秒并检查服务器命令，不暴力连点
- 系统邮箱界面缺位时，仍可用斜杠命令工作

## 安装

把整个 `KMail` 文件夹放到：

World of Warcraft\_forever_\Interface\AddOns\KMail\

其中应包含 `KMail.lua`、`KMail.toc`、`KMail.png` 三个文件。进游戏后在插件列表启用。

## 命令

| 命令 | 作用 |
|---|---|
| `/km` 或 `/kmail` | 打开通讯录 |
| `/km get` | 一键收取全部金币与附件（不删信） |
| `/km stop` | 停止收取 |
| `/km fav 名字` | 收藏；不带名字则收藏当前收件人 |
| `/km unfav 名字` | 取消收藏 |
| `/km alt 名-姓` | 手动加入小号（需完整全名） |
| `/km altscan` | 重新扫描同账号角色 |
| `/km show` / `/km hide` | 强制显示 / 恢复自动跟随邮箱工具条 |
| `/km test` | 接口自检，排错第一步 |
| `/km help` | 帮助 |

## 备注

基于 forever 分支 1.60.x 客户端 API 开发，不适用于正式服或怀旧服。
